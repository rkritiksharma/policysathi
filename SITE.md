# PolicySathi Site Structure

## Vision
A highly modern, premium web platform where users can easily compare, buy, and manage insurance policies in India. The emphasis is on transparency, trust, speed, and premium design.

## SITEMAP
- [ ] / (Landing Page - Hero with dynamic ticker)
- [ ] /dashboard (User's main hub)
- [ ] /dashboard/policies (List of user policies)
- [ ] /login (Authentication layout)

## ROADMAP
1. Create `/` Landing Page component.
2. Create `/dashboard` Layout and Main Overview component.
3. Create `/login` Split Pane authentication screen.

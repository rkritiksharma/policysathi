# PolicySathi Design System

This file documents the visual language and constraints for the AI-generated UI components. The `stitch-loop` skill must use this configuration to maintain consistency.

## Brand Identity
- **Personality:** Premium, Trustworthy, Modern, Transparent
- **Target Audience:** Indian families looking for accessible and secure policy management

## Color Palette
- **Primary (Sapphire):** `#0A192F` (Deep, secure financial feel)
- **Secondary (Emerald):** `#10B981` (Growth, safety, success)
- **Background (Light Mode):** `#FFFFFF` or very soft gray `#F8FAFC`
- **Background (Dark Mode):** `#0F172A`
- **Text (Primary):** `#1E293B` (for light mode), `#F8FAFC` (for dark mode)
- **Text (Muted):** `#64748B` (for light mode), `#94A3B8` (for dark mode)

## Typography
- **Font Family:** `Inter`, `Outfit`, or `Roboto`
- **Headings:** Bold, clean, high contrast
- **Body Text:** Minimum 16px for readability

## UI Elements
- **Cards:** Soft drop shadows (`shadow-sm` or `shadow-md`), subtle borders (`border-slate-200` in light mode or `border-slate-800` in dark mode), rounded corners (`rounded-xl` or `rounded-2xl`).
- **Buttons:** Solid primary buttons with a slight hover lift (`hover:-translate-y-0.5`) and smooth transition.
- **Inputs:** Clean borders, clear focus states (e.g., ring-emerald-500).

## Note for Stitch Generation
Whenever generating a screen, please stick strictly to this color palette and typography. Ensure all components feel premium with ample whitespace (`padding: 24px` or more for main containers). Use modern aesthetics like subtle glassmorphism for floating navbars or modals if applicable.
